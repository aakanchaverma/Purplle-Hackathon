Store Intelligence System

Overview:
This project analyzes retail store surveillance footage using YOLOv8-based person detection and tracking. The system automatically generates visitor movement events, computes dwell times, analyzes billing queue behavior, and provides business insights through an interactive Streamlit dashboard.

Core Features:
- Entry and Exit Monitoring
- Footfall Analytics
- Zone-wise Customer Tracking
- Dwell Time Measurement
- Billing Queue Analysis
- Store Performance Metrics
- Interactive Dashboard
- Business Recommendations

Technology Stack:
- Python
- YOLOv8
- OpenCV
- Streamlit
- Pandas

Output:
Structured JSONL event files are generated from video streams and consumed by the analytics layer to create operational and business intelligence reports.
